# Security Policy

## Supported Versions

Security updates are applied to the active `main` branch and the latest stable release.

| Version | Supported |
| :--- | :--- |
| Latest release (`v*`) | :white_check_mark: |
| `main` branch | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

We take the security of Tunward seriously. If you discover a security vulnerability, please report it privately rather than creating a public issue.

### How to report

Send an email to **fahmi@kemal.id** with:
- A descriptive summary of the vulnerability.
- Steps to reproduce the issue (proof of concept, CLI commands, or sample configuration).
- The affected component (client, server, transport layer, or parser).
- Potential impact and severity.

Alternatively, you can open a private security advisory through the GitHub repository under the **Security** tab.

### Response timeline

- **Initial acknowledgment:** Within 48 hours of receipt.
- **Assessment and triage:** We will evaluate the impact and keep you informed of remediation progress.
- **Fix and disclosure:** A patch will be released along with a security advisory once validated. We kindly ask that you maintain responsible disclosure until the fix is published.
